# Historial de versiones / Version history

[Versión actual / Current version](https://github.com/sruizdeaguiar-svg/Agentic-Studio/tree/main)

Esta rama conserva las versiones anteriores fuera de `main`. Las instantáneas 0.5.0 y 0.5.1 incluyen el código público completo de macOS, backend e iOS; las exportaciones 0.1.0–0.4.2 son parciales. Las exportaciones 0.1.0–0.4.2 contienen únicamente el backend Python y la interfaz web recuperables de compilaciones conservadas. No incluyen código nativo histórico completo, binarios, datos, credenciales ni firmas personales. Las rutas personales se han saneado y la marca se ha normalizado a Agentic Studio; no son copias bit a bit de los paquetes originales. No se inventa código no disponible.

**No instalar para uso real:** estas versiones preceden a las correcciones de seguridad actuales. Usa la versión de `main` y sus notas de seguridad.

This branch keeps previous versions outside `main`. Snapshots 0.5.0 and 0.5.1 include complete public macOS, backend and iOS source; snapshots 0.1.0–0.4.2 are partial. Historical exports 0.1.0–0.4.2 contain only the Python backend and web interface recoverable from retained builds. They do not include complete historical native source, binaries, user data, credentials or personal signatures. Personal paths were sanitized and branding normalized to Agentic Studio; these are not bit-for-bit copies of the original packages. Unavailable source is not reconstructed or invented.

**Do not deploy these snapshots:** they predate current security fixes. Use `main` and read its security notes.
