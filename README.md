# Historial de versiones / Version history

[Versión actual / Current version](https://github.com/sruizdeaguiar-svg/Agentic-Studio/tree/main)

Esta rama conserva las versiones anteriores fuera de `main`. Las exportaciones históricas contienen únicamente el backend Python y la interfaz web recuperables de compilaciones conservadas. No incluyen código nativo histórico completo, binarios, datos, credenciales ni firmas personales. Las rutas personales se han saneado y la marca se ha normalizado a Agentic Studio; no son copias bit a bit de los paquetes originales. No se inventa código no disponible.

**No instalar para uso real:** estas versiones preceden a las correcciones de seguridad actuales. Usa la versión de `main` y sus notas de seguridad.
