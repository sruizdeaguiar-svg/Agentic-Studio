Carpeta y permisos del agente
Archivos: listar, leer y buscar dentro de esta carpeta. Los comandos y sus procesos hijos usan aislamiento de macOS, sin acceso a otros proyectos ni a la red. Pueden leer las herramientas y bibliotecas del sistema necesarias para ejecutarse.
Si la escritura requiere revisión, los comandos también se revisan. Sin aislamiento, el agente se detiene y pregunta al usuario. No se amplían los permisos automáticamente.


MCP y navegador del proyecto
Servidores MCP · stdio y HTTP remoto
Stdio: solo ejecutables instalados. Código del servidor dentro de la carpeta autorizada o del runtime del sistema. Sin red y sin variables de entorno heredadas. No pongas credenciales en los argumentos. Las herramientas nuevas empiezan denegadas.
Remoto: HTTPS Streamable HTTP; HTTP solo en loopback para pruebas. OAuth usa PKCE y el llavero de macOS. No guardes tokens en este JSON. Sin envío de carpetas ni credenciales al modelo.
OAuth abre el navegador del sistema solo para la autorización. Revisa proveedor, endpoints y scopes. El cliente debe ser público; puedes indicar un client_id registrado o usar registro dinámico si el proveedor lo ofrece. No se admiten client_secret. Las herramientas remotas que no declares de solo lectura se bloquean si el proyecto prohíbe escritura.
Navegador privado · una página
Cada página es una sesión privada del proyecto. Se revisan clics y texto según estos permisos. Sin acceso a archivos locales, cargas, descargas, contraseñas, ventanas emergentes ni JavaScript arbitrario del agente. Se filtran navegación y recursos HTTP(S) por origen. No se usa tu navegador personal. La página y MCP se liberan tras 60 segundos de inactividad.
